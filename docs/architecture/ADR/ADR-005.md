# ADR-005: Estratégia de Anonimização e Pseudonimização de Dados PII

- **Status:** Aceito
- **Data:** 2026-07-05
- **Decisores:** Leonardo Lucas Pereira

---

## Contexto

O BAIP processa dados sensíveis relacionados a saúde pública, incluindo registros de triagem hospitalar com informações potencialmente identificáveis, como CPF e CNPJ.

Esses dados são utilizados para geração de indicadores epidemiológicos, análises históricas e processamento near real-time.

Para atender requisitos de segurança e conformidade com a LGPD, é necessário garantir que dados pessoais identificáveis (PII) não sejam propagados para camadas analíticas (Silver, Gold e Data Warehouse).

---

## Decisão

A estratégia adotada para tratamento de dados PII será baseada em **pseudonimização via tokenização determinística com hash criptográfico (SHA-256 + salt)**.

### Processo definido:

1. O sistema de ingestão recebe o CPF/CNPJ na camada de entrada (Bronze);
2. Um serviço de anonimização gera um identificador pseudonimizado (`patient_id`);
3. O CPF não é propagado para as camadas Silver, Gold ou Data Warehouse;
4. O `patient_id` será utilizado como chave substituta em toda a arquitetura analítica.

---

## Implementação da solução

### Geração do token

O identificador será gerado utilizando:

- Hash criptográfico (SHA-256);
- Salt controlado pela plataforma (armazenado no AWS Secrets Manager);
- Função determinística (mesmo CPF sempre gera o mesmo ID interno).
