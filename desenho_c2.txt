1. Fontes públicas disponibilizam dados históricos e atualizados:
   saúde, população, clima, infraestrutura e eventos naturais.

2. Batch Ingestion Jobs coletam os dados dessas fontes.

3. Os dados brutos são armazenados no S3 Bronze,
   mantendo histórico, rastreabilidade e possibilidade de reprocessamento.

4. Glue ETL Jobs leem a Bronze, padronizam schemas,
   tratam tipos, removem duplicidades e validam qualidade.

5. Dados inválidos ou suspeitos são enviados para uma área de Quarantine no S3.

6. Dados tratados são gravados na S3 Silver,
   já padronizados, com PII removida/tokenizada quando aplicável.

7. Glue ETL Jobs enriquecem a Silver com dimensões como município,
   UF, população, clima, infraestrutura hospitalar e calendário epidemiológico.

8. Dados analíticos consolidados são gravados na Gold/Data Warehouse.

9. Glue Data Catalog cataloga tabelas Bronze, Silver, Gold e DW.

10. Athena consulta as tabelas analíticas.

11. Power BI consome views/tabelas da Gold/DW via Athena.

12. Em paralelo, o Sistema Hospitalar ou Simulador de Triagem publica eventos
    de novos atendimentos suspeitos.

13. Os eventos entram no SQS.

14. Lambda consome eventos do SQS, valida schema contract,
    aplica idempotência e tokenização/pseudonimização.

15. Eventos processados atualizam indicadores recentes no DynamoDB.

16. Eventos com erro após múltiplas tentativas vão para a DLQ.

17. Eventos válidos também podem ser persistidos no S3 Silver/NRT,
    para reconciliação posterior com dados batch oficiais.

18. Step Functions orquestra pipelines batch,
    qualidade, enriquecimento, Gold e reconciliação.

19. CloudWatch monitora jobs, Lambda, filas, erros, latência e custos.

20. KMS, IAM, Lake Formation e Secrets Manager protegem acesso,
    criptografia, segredos e dados sensíveis.
